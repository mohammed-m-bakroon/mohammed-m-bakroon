## 🧭 How I build

- **Modular by default.** Features live in their own modules (admin, courses, orders, users), so large Laravel apps stay easy to navigate and change.
- **Access control that is real.** Roles and permissions drive both the API and the admin panel, not just the menu.
- **Secure content and accounts.** Signed URLs, HLS / AES-128 encrypted video, and verification codes scoped per user.
- **Repeatable deployments.** Fixes are committed to Git and shipped through CI/CD, never applied only on the server.
- **Multilingual products.** Arabic (RTL), English and more, with translatable content and a review process for it.
- **Tested and typed.** Automated tests and strict typing on the code I publish.
